# ☁️ Cloud Fundamentals Lab (Azure)

## 📌 Project Objective

This project explains cloud computing concepts with practical exposure using Microsoft Azure.
Designed for beginners to understand and transition into cloud roles.

---

## 📘 What is Cloud Computing?

Cloud computing is the delivery of computing services (servers, storage, networking, databases) over the internet.

---

## ❓ Why Cloud?

* No need to maintain physical hardware
* Scalable on demand
* Cost-effective
* Global accessibility

---

## 🧠 Cloud Service Models

### 🔹 IaaS (Infrastructure as a Service)

* You manage OS, apps
* Example: Azure Virtual Machine

### 🔹 PaaS (Platform as a Service)

* Platform managed by provider
* Example: Azure App Services

### 🔹 SaaS (Software as a Service)

* Fully managed software
* Example: Microsoft 365

## 🔥 Interview Questions

### Q1: What is cloud computing?

Cloud computing is delivering IT services over the internet instead of local servers.

### Q2: Difference between IaaS, PaaS, SaaS?

* IaaS → Full control
* PaaS → Platform managed
* SaaS → Fully managed
